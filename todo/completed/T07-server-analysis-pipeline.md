# T07 一页分析流水线与 Worker

阶段：S0 server
状态：已完成（v0.7，2026-09-26）

## 要做什么
按 `docs/system-design.md` 第 5 节实现：`POST /analyses` 先调安全规则引擎，再创建排队任务并返回 202 与任务 ID（附安全提示）；Worker 为独立进程 `npm run worker`，轮询 SQLite 任务表消费；只在证据库内检索；通过大模型适配层（默认本地模拟实现）生成固定五段（已知 / 解释 / 未知 / 下一步 / 视频），缺失即未知、不补写概率；陈述提取与引用核对，剔除无依据的陈述；保存分析版本及模型、检索、内容版本快照；`GET /analyses/{id}`；每条解释可定位到报告原文；模型、检索或来源校验失败时返回明确的回退状态，不无限重试。

## 完成标准
- 不启动 Worker 时任务保持排队，启动后完成
- 分析结果中每条解释都带来源
- 相关构建、类型检查、测试全部通过
