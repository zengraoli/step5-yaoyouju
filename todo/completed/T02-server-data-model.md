# T02 数据模型与种子数据

阶段：S0 server
状态：已完成（v0.2，2026-09-26）

## 要做什么
按 `docs/system-design.md` 第 3 节的 ER 建表：业务库 `server/data/app.db` 与身份隔离库 `server/data/identity.db` 分开，手机号和姓名用 AES-256-GCM 加密存储。种子数据：2 个演示用户（各带病程、病程事件、报告、一次分析）、10 条内容（覆盖各审核状态）、6 篇证据文档、5 个后台角色各一个账号、若干功能开关、1 个评测集。

## 完成标准
- 启动时自动建表并写入种子数据，重复启动不会重复写入
- 身份库中的手机号、姓名为密文
- 相关构建、类型检查、测试全部通过
